

---

一、前台展示模块（Vue）

1. 个人信息展示

- 博主信息：头像、昵称、博客标题、超链接、QQ、GitHub、Gitee、Bilibili 社交图标的 link。
- 个人档案：出生年月、性别、现职业、个性标签、爱好（数组形式展示）、爱好游戏（JSON/数组展示）。
- 地理位置：基于经纬度渲染地图或显示文字地址。
- 访问统计：今日访问、访问人数（UV）、本月访问、总访问量（PV）。

2. 文章与内容模块

- 文章列表：分页展示，支持按标签分类筛选。
- 文章详情：Markdown 渲染、代码高亮。
- 全局搜索：支持按标题、内容、标签进行模糊搜索。

3. 互动模块（留言与评论）

- 游客登录/身份绑定：前端提交昵称、邮箱、头像（可默认头像或输入 URL）。
- 树状评论展示：支持多级嵌套回复（楼中楼模式）。
- 评论表单：支持输入内容、@某人（从已有评论列表选择或输入）、提交头像/名称/邮箱。
- 评论：每篇文章独立的评论区。

4. 友链模块

- 友情链接展示：展示友站名称、头像、描述、URL。

---

二、后台管理模块（Vue + Spring Boot）

1. 仪表盘（Dashboard）

- 核心数据看板：今日访问、本月访问、总访问量、文章总数、评论总数、待审核评论数。

2. 文章管理

- Markdown 编辑器：集成支持代码高亮的编辑器（如 md-editor-v3）。
- 标签管理：发布文章时选择或新增标签，支持标签的增删改查。
- 文章列表：支持编辑、删除、状态切换（发布/下架）。

3. 评论与留言管理

- 审核机制：游客提交的评论默认进入"待审核"状态，管理员审核通过后才在前台展示。
- 评论列表：树状结构展示所有评论，支持直接回复、删除、标记为垃圾评论。

4. 友链管理

- 添加、编辑、删除、排序友情链接。

5. 个人设置管理

- 修改头像、昵称、职业、爱好、社交链接等个人信息。
- 修改经纬度地址。

6. 系统设置

- 邮件通知配置：配置 SMTP 服务器信息（发件邮箱、授权码），用于接收评论提醒。
- 评论开关：全局开启/关闭评论功能、开启/关闭审核机制。

---

三、核心业务逻辑与接口设计

1. 评论与 @某人 逻辑

- 数据结构：评论表需包含 parent_id（父评论 ID）和 reply_to_user_id（被回复人 ID）。
- @某人 解析：前端提交时记录被回复人 ID，后端在渲染树状结构时根据 parent_id 组装嵌套关系。
- 邮件通知触发
  ：
    - 游客评论 → 触发邮件通知博主（管理员）。
    - 游客 A 回复游客 B → 触发邮件通知游客 B（需验证游客 B 邮箱真实性，可选）。

2. 访问统计逻辑

- 防刷机制：基于 IP + User-Agent + 日期进行 Redis 缓存去重，避免重复计算 UV。
- 异步写入：访问日志先写 Redis，定时任务批量同步到 MySQL，减轻数据库压力。
