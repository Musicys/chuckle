# 访问统计

## 记录访问

**接口说明**：前端页面加载时调用，记录一次访问（自动获取访问者IP和User-Agent）。每次页面加载/路由切换时均应调用此接口，以保证统计数据准确。

**请求方式**：`POST`

**接口路径**：`/visits/record`

**请求参数**（JSON Body，可选）：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageUrl | string | 否 | 当前访问的页面URL（不传则记录空字符串） |

**请求示例**：

```json
"/articles/1"
```

**响应示例**：

```json
{
  "code": 0,
  "data": null,
  "message": "ok"
}
```

---

## 获取访问统计

**接口说明**：获取博客的访问统计数据，从访问日志实时聚合计算

**请求方式**：`GET`

**接口路径**：`/visits/stats`

**请求参数**：无

**响应示例**：

```json
{
  "code": 0,
  "data": {
    "todayPv": 1321,
    "todayUv": 421,
    "monthPv": 8532,
    "totalPv": 128532
  },
  "message": "ok"
}
```

**响应字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| todayPv | int | 今日访问量（页面浏览量） |
| todayUv | int | 今日访客数（独立IP去重） |
| monthPv | int | 本月访问量 |
| totalPv | int | 总访问量 |

**注意事项**：
- 统计数据来源于访问日志表（visit_logs），实时聚合
- todayUv 基于 IP 去重统计
- 所有记录为空时返回 0
- 无需登录即可访问
