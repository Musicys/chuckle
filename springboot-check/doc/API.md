# API 接口文档

## 接口位置

- `com.yupi.springbootinit.controller.user` — 客户端接口（博客前端）
- `com.yupi.springbootinit.controller.admin` — 管理端接口（后台管理）

## 接口前缀

所有接口以 `/api` 开头，默认端口 `8088`。

启动后访问 Swagger 文档：`http://localhost:8088/api/doc.html`

详见 [user_api.md](./user_api.md)
